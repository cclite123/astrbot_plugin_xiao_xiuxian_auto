# 小小修仙 (XiaoXiuxian)

> 基于 [AstrBot](https://github.com/Soulter/AstrBot) 的 QQ 群修仙游戏全自动挂机插件 —— 悬赏、秘境、宗门、炼丹、签到、挖矿、灵田、闭关修炼，一键解放双手。

---

## 功能特性

| 模块 | 说明 |
|------|------|
| **自动悬赏** | 每日自动探测悬赏令，支持"修为/价值/耗时"三种策略择优接取，自动结算循环 |
| **自动秘境** | 定时探索秘境，自动结算并循环探测，支持多区域识别 |
| **宗门任务** | 自动接取宗门密令/除魔/仙丹/疏财/红尘等任务，气血不足时自动恢复 |
| **自动签到/领丹** | 每日定时修仙签到 + 宗门丹药领取，带防重复确认机制 |
| **自动挖矿** | 定时挖灵石，约 5 小时静默周期，防止刷屏 |
| **自动灵田** | 灵田结算收取，自动解析下次收成时间并定时执行 |
| **自动修炼/闭关** | 修炼、闭关、宗门闭关三种模式，气血监控，活动冲突自动挂起与恢复 |
| **一键上架** | 自动遍历背包分页，按坊市实时价格批量上架药材/装备/神物/丹药 |
| **一键炼金** | 自动遍历背包分页，按白/黑名单规则批量炼金 |
| **自动炼丹** | 支持批量模式/指定丹药/背包炼丹，自动扫描坊市 8 页药材价格、利润计算、批量购买+炼制全流程 |
| **坊市价格中心** | 混合数据源（远程 API + 本地缓存），附带独立 FastAPI 服务端可供多人共享价格 |
| **多账号/多群** | 支持多 QQ 账号绑定、多群独立运行，互不干扰 |
| **任务协调器** | 多模块间指令排队发送，避免冲突；闭关保护机制防止操作中断 |

## 技术栈

- **语言**: Python 3.10+
- **框架**: [AstrBot](https://github.com/Soulter/AstrBot) 插件体系 (Star / AstrMessageEvent)
- **协议**: OneBot / QQ Markdown 消息解析
- **存储**: JSON 文件持久化 (JsonStore)，原子写入防损坏
- **价格服务**: FastAPI + Uvicorn（可选独立部署）
- **异步**: asyncio 全异步架构，定时 tick 循环驱动状态机

## 安装与配置

### 前置要求

- Python 3.10+
- [AstrBot](https://github.com/Soulter/AstrBot) 已安装并运行
- QQ 群中已添加"小小"官方机器人

### 安装步骤

1. **克隆仓库到 AstrBot 插件目录**

   ```bash
   cd <astrbot>/data/plugins
   git clone https://github.com/cclite123/xiaoxiuxian.git
   ```

2. **安装依赖**

   ```bash
   pip install pyyaml    # 可选，用于 herb_max_prices.yaml 解析
   ```

3. **编辑配置文件**

   打开 `config.json`，按需调整：

   ```json
   {
     "official_bot_qq": "3889001741",   // 官方机器人 QQ 号
     "test_mode": false,                 // 测试模式（true = 不发真实指令）
     "bounty": {
       "default_strategy": "价值",       // 悬赏策略：修为 / 价值 / 耗时
       "daily_start_time": "08:30"       // 每日自动启动时间
     },
     "secret": {
       "daily_start_time": "12:35"       // 秘境每日启动时间
     }
   }
   ```

4. **重启 AstrBot** 即可自动加载插件。

## 使用方法

在已绑定的 QQ 群中发送以下指令（需 @小小机器人）：

### 基础指令

| 指令 | 说明 |
|------|------|
| `开启自动悬赏` | 启动自动悬赏（按配置策略自动选优） |
| `关闭自动悬赏` | 停止自动悬赏 |
| `悬赏策略 价值` | 切换悬赏策略（修为/价值/耗时） |
| `开启自动秘境` | 启动自动秘境探索 |
| `关闭自动秘境` | 停止自动秘境 |
| `开启宗门任务` | 启动自动宗门任务 |
| `开启自动签到` | 每日自动修仙签到 |
| `开启自动领丹` | 每日自动领取宗门丹药 |
| `开启自动挖矿` | 定时自动挖灵石 |
| `开启自动灵田` | 自动灵田收取 |

### 修炼指令

| 指令 | 说明 |
|------|------|
| `开启自动修炼` | 自动修炼模式 |
| `开启自动闭关` | 自动闭关模式 |
| `开启宗门闭关` | 自动宗门闭关模式 |
| `关闭自动修炼` | 关闭当前修炼/闭关 |

### 背包操作

| 指令 | 说明 |
|------|------|
| `一键上架 药材` | 按坊市价格自动上架药材 |
| `一键上架 装备` | 自动上架装备（已装备自动跳过） |
| `一键炼金 丹药` | 按白名单自动炼金丹药 |
| `一键炼金 神物` | 按黑名单过滤后自动炼金 |

### 炼丹指令

| 指令 | 说明 |
|------|------|
| `开启自动炼丹` | 启动自动炼丹（批量模式） |
| `炼丹 摄魂鬼丸 3` | 指定丹药炼制 3 炉 |
| `背包炼丹` | 使用背包已有药材炼丹 |
| `暂停炼丹` / `继续炼丹` / `关闭炼丹` | 炼丹流程控制 |

### 管理指令

| 指令 | 说明 |
|------|------|
| `自动状态` | 查看所有自动任务当前状态 |
| `绑定` | 将当前群绑定为操作目标 |
| `解绑` | 解除群绑定 |
| `菜单` | 查看完整指令菜单 |

## 坊市价格中心（可选）

如需多人共享坊市价格数据，可独立部署价格服务：

```bash
cd market_price_server
pip install fastapi uvicorn
MARKET_WRITE_TOKEN="your-secret-token" uvicorn server:app --host 0.0.0.0 --port 8808
```

然后在 `config.json` 中配置：

```json
{
  "market_price": {
    "source": "hybrid",
    "remote_url": "http://your-server:8808/api/prices/latest",
    "api_key": ""
  }
}
```

## 架构设计

本插件采用 **状态机 + 定时 tick** 架构：

- 每个功能模块（悬赏/秘境/宗门等）都有独立的 `Controller` 和 `State` 数据类
- 状态通过 `JsonStore` 持久化到 JSON 文件，重启不丢失
- 主循环 `_tick_loop` 每 2 秒扫描所有活跃任务，检查是否到达唤醒时间
- 所有模块共用同一个消息发送队列，通过 `coordinator` 排队发送，避免指令冲突
- 修炼/闭关模块与其他活动模块联动：活动开始时自动出关，活动结束后自动恢复
