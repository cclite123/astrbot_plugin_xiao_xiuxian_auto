# 小小修仙 (XiaoXiuxian)

> 基于 [AstrBot](https://github.com/Soulter/AstrBot) 的 QQ 群修仙游戏任务挂机插件 —— 悬赏、秘境、宗门、炼丹、签到、挖矿、灵田、闭关修炼，一键解放双手。

---

## 功能特性

| 模块 | 说明 |
|------|------|
| **悬赏** | 每日探测悬赏令，支持"修为/价值/耗时"三种策略择优接取，结算循环 |
| **秘境** | 定时探索秘境，结算并循环探测，支持多区域识别 |
| **宗门任务** | 接取宗门密令/除魔/仙丹/疏财/红尘等任务，气血不足时恢复 |
| **签到/领丹** | 每日定时修仙签到 + 宗门丹药领取，带防重复确认机制 |
| **挖矿** | 定时挖灵石，约 5 小时静默周期，防止刷屏 |
| **灵田** | 灵田结算收取，解析下次收成时间并定时执行 |
| **修炼/闭关** | 修炼、闭关、宗门闭关三种模式，气血监控，活动冲突挂起与恢复 |
| **一键上架** | 遍历背包分页，按坊市实时价格批量上架药材/装备/神物/丹药 |
| **一键炼金** | 遍历背包分页，按白/黑名单规则批量炼金 |
| **炼丹** | 支持批量模式/指定丹药/背包炼丹，扫描坊市 8 页药材价格、利润计算、批量购买+炼制全流程 |
| **灵界升级** | 查询灵界状态后按 ROI 性价比建造、升级建筑、招募杂役、杂役升阶和技艺修行 |
| **无尽妖塔** | 支持无限或指定次数挑战，挑战前可检测真元，不足时宗门闭关恢复 |
| **坊市价格中心** | 混合数据源（远程 API + 本地缓存），附带独立 FastAPI 服务端可供多人共享价格 |
| **多账号/多群** | 支持多 QQ 账号绑定、多群独立运行，互不干扰 |
| **任务协调器** | 多模块间指令排队发送，避免冲突；闭关保护机制防止操作中断 |

## 技术栈

- **语言**: Python 3.10+
- **框架**: [AstrBot](https://github.com/Soulter/AstrBot) 插件体系 (Star / AstrMessageEvent)
- **协议**: OneBot / QQ Markdown 消息解析
- **存储**: JSON 文件持久化 (JsonStore)，原子写入防损坏
- **价格服务**: FastAPI + Uvicorn（可选独立部署）
- **异步**: asyncio 全异步架构，定时 tick 循环驱动状态机

## 安装与配置

### 前置要求

- Python 3.10+
- [AstrBot](https://github.com/Soulter/AstrBot) 已安装并运行
- QQ 群中已添加"小小"官方机器人

### 安装步骤

1. **克隆仓库到 AstrBot 插件目录**

   ```bash
   cd <astrbot>/data/plugins
   git clone https://github.com/cclite123/astrbot_plugin_xiao_xiuxian_auto.git
   ```

2. **安装依赖**

   ```bash
   pip install pyyaml    # 可选，用于 herb_max_prices.yaml 解析
   ```

3. **编辑配置文件**

   打开 `config.json`，按需调整：

   ```json
   {
     "official_bot_qq": "3889001741",   // 官方机器人 QQ 号
     "test_mode": false,                 // 测试模式（true = 不发真实指令）
     "bounty": {
       "default_strategy": "价值",       // 悬赏策略：修为 / 价值 / 耗时
       "daily_start_time": "08:30"       // 每日自动启动时间
     },
     "secret": {
       "daily_start_time": "12:35"       // 秘境每日启动时间
     },
     "sect": {
       "daily_start_time": "06:30",      // 宗门任务默认每日启动时间
       "default_enabled_tasks": ["密令", "除魔"]
     }
   }
   ```

4. **重启 AstrBot** 即可自动加载插件。

### 宗门任务配置

`config.json` 中的 `sect` 配置用于控制宗门任务模块：

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| `daily_start_time` | `"06:30"` | 首次创建账号宗门任务状态时使用的每日启动时间，格式为 `HH:MM`。 |
| `default_enabled_tasks` | `[]` | 首次创建时默认开启的目标任务，可选：`密令`、`除魔`、`仙丹`、`疏财`、`红尘`。空列表表示不预选。 |
| `response_timeout_sec` | `120` | 接取、刷新或完成任务后等待有效回执的超时时间（秒）。 |
| `task_refresh_delay_sec` | `70` | 接到非目标任务后，等待多久发送“宗门任务刷新”（秒）。 |
| `hp_recovery_min_sec` | `180` | 气血不足后进入恢复状态的最短等待时间（秒）。 |
| `hp_recovery_cultivate_count` | `3` | 修炼回血模式下，收到多少次修炼回执后视为恢复完成。 |

`daily_start_time` 和 `default_enabled_tasks` 只会应用于首次创建的账号状态，避免覆盖已经通过聊天指令设置的时间和目标。已有账号可使用 `宗门任务时间 HH.MM`、`开启宗门任务…`、`关闭宗门任务…` 调整。

示例：

```json
{
  "sect": {
    "daily_start_time": "07:30",
    "default_enabled_tasks": ["密令", "除魔", "仙丹"],
    "response_timeout_sec": 120,
    "task_refresh_delay_sec": 70,
    "hp_recovery_min_sec": 180,
    "hp_recovery_cultivate_count": 3
  }
}
```

### WebUI 配置中心

插件提供了一个 WebUI 配置页面。请在 AstrBot 管理后台的**插件详情页**中打开本插件的 Page（“小小修仙 · 配置中心”）。不要直接用浏览器打开 `pages/config/index.html`，否则页面会进入预览模式，无法读取或保存实际配置。

在配置中心中可以：

- 按模块切换和搜索所有由 `_conf_schema.json` 定义的配置项，包括“宗门任务模块配置”；列表配置可按行填写，也可用逗号分隔；
- 修改普通配置项后点击 **保存并热重载**；
- 在“炼金名单”页面维护丹药白名单、装备黑名单和神物黑名单；
- 在“药材上限价”页面维护炼丹的药材最高购买价；
- 查看当前绑定会话数、测试模式和坊市价格模块状态。

保存普通配置时，插件会写入 `data/page_config_override.json` 并热重载全部模块。配置优先级为：`config.json` < AstrBot 注入配置 < WebUI 覆盖配置。热重载会中断正在进行的自动任务，建议在悬赏、炼丹、宗门任务等操作空闲时保存。

若管理后台没有显示该 Page，或页面提示 Web API 不可用，请先升级到支持插件 Page 与 `register_web_api` 的 AstrBot 版本；也可以直接编辑 `config.json` 后重启 AstrBot。

## 使用方法

在已绑定的 QQ 群中发送以下指令（需 @小小机器人）：

### 基础指令

| 指令 | 说明 |
|------|------|
| `开启悬赏` | 启动悬赏（按配置策略选优） |
| `关闭悬赏` | 停止悬赏 |
| `悬赏价值` | 切换悬赏策略（修为/价值/耗时） |
| `开启秘境` | 启动秘境探索 |
| `关闭秘境` | 停止秘境 |
| `开启宗门任务` / `关闭宗门任务` | 启动或停止宗门任务 |
| `宗门任务状态` | 查看宗门任务状态、执行时间和已启用目标 |
| `宗门任务时间 07.30` | 设置当前账号的宗门任务每日执行时间 |
| `开启宗门任务 密令 除魔` | 为当前账号开启指定目标任务 |
| `关闭宗门任务 红尘` | 为当前账号关闭指定目标任务 |
| `开启签到` | 每日修仙签到 |
| `开启领丹` | 每日领取宗门丹药 |
| `开启挖矿` | 定时挖灵石 |
| `开启灵田` | 灵田收取 |
| `开启灵界升级` | 启动灵界升级，按 ROI 执行到灵矿石不足 |
| `关闭灵界升级` | 停止灵界升级 |
| `灵界规划` | 查看下一次 ROI 推荐升级项 |
| `灵界刷新规划` | 强制重新查询灵界页面后输出推荐项 |
| `灵界规划详情` | 查看 ROI 前几名、缓存时间和灵符堂是否进入候选 |
| `灵界状态` | 查看灵界升级模块缓存和运行状态 |
| `开启无尽` | 启动无尽妖塔，无限挑战 |
| `开启无尽 100` | 挑战无尽妖塔 100 次后停止 |
| `关闭无尽` | 停止无尽妖塔 |
| `开启真元检测` / `关闭真元检测` | 开关挑战前真元检测 |
| `设置真元检测 600` | 设置真元阈值，范围 0-9999 |
| `无尽状态` | 查看无尽妖塔运行状态 |

首次启动新版插件时，会自动在本地 `config.json` 中补齐缺失的 `linjie_upgrade`、`endless_tower` 配置项；已有配置值不会被覆盖。
默认 `roi_formula_source` 为 `excel_formula`，即按本地 Excel 复刻公式计算 ROI；如需按游戏回执显示的单项增量计算，可改为 `game_display`。

## 坊市价格中心（可选）

如需多人共享坊市价格数据，可独立部署价格服务：

```bash
cd market_price_server
pip install fastapi uvicorn
MARKET_WRITE_TOKEN="your-secret-token" uvicorn server:app --host 0.0.0.0 --port 8808
```

然后在 `config.json` 中配置：

```json
{
  "market_price": {
    "source": "hybrid",
    "remote_url": "http://your-server:8808/api/prices/latest",
    "api_key": ""
  }
}
```

## 架构设计

本插件采用 **状态机 + 定时 tick** 架构：

- 每个功能模块（悬赏/秘境/宗门等）都有独立的 `Controller` 和 `State` 数据类
- 状态通过 `JsonStore` 持久化到 JSON 文件，重启不丢失
- 主循环 `_tick_loop` 每 2 秒扫描所有活跃任务，检查是否到达唤醒时间
- 所有模块共用同一个消息发送队列，通过 `coordinator` 排队发送，避免指令冲突
- 修炼/闭关模块与其他活动模块联动：活动开始时自动出关，活动结束后自动恢复
